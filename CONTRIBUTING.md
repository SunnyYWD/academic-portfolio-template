# Contributing

Thanks for helping improve this academic portfolio template. Bug reports, documentation fixes, accessibility improvements, translations, and small reusable features are welcome.

## Before you start

- Check existing issues and pull requests to avoid duplicate work. For a substantial change, open an issue first to discuss the approach.
- Keep the starter content fictional. Do not add real names, contact details, headshots, affiliations, publication records, API keys, or other personal information to the template.
- Keep English and Chinese examples in sync when changing visible copy or content structure.
- Avoid new runtime trackers, externally loaded fonts, or third-party services unless the change has been discussed first.

## Make a change

1. Fork the repository and create a branch for your change.
2. Install dependencies with `npm ci`.
3. Run `npm run dev` to check the page in both languages and at mobile and desktop widths.
4. Run `npm run build` before opening a pull request.
5. Explain what changed, why it helps template users, and how you tested it. Include screenshots for visual changes.

Please keep pull requests focused and avoid committing generated `dist/` files or local dependencies. Contributions are submitted under the repository's MIT license.

## Reporting an issue

Include the steps to reproduce, expected and actual behavior, browser and device details when relevant, and a screenshot if it helps. Remove personal data from logs and screenshots before posting.
